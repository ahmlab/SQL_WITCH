# assets/audio/

Every sound the game plays, and `sounds.json`, which says which file plays for each event.

## Use your own sound

1. Put the file in this folder (`.wav` or `.ogg`; `.mp3` works for music).
2. In `sounds.json`, change the `file` of the event to your file name.
3. Adjust `volume` (0.0 to 1.0) if needed. `master_volume` scales everything.

An event can list several files with `"files": [...]` instead of `"file"`; the game picks one
by context (the typing notes use this).

No code changes are needed. If a file is missing, the game prints one warning and keeps
going without that sound.

## Events

| Event | When it plays |
|---|---|
| `hit` / `crit` | A spell lands (crit: a critical hit, with screen shake). |
| `hp_down` / `hp_up` | An HP bar drains (damage) or fills (heal, Healing Herb). |
| `mp_down` / `mp_up` | An MP bar drains (casting) or fills (end of round, Ether). |
| `cast` | A query that casts something is sent (Ada's or the Slime's). Also wards. |
| `scry` | A free look: a query that casts nothing. |
| `fizzle` | Spells fizzle: rows lost in the margin, duplicates, no MP left. |
| `miscast` | A rejected query: the book puffs smoke. |
| `invitation` | The Slime's `LIMIT` glows and Ada learns the rune. |
| `faint` | A combatant falls. |
| `typing` | Every letter typed in the Grimoire. It has 8 files (`files` list): the letters of a word climb through them like a scale, so typing plays a melody. |
| `erase` / `newline` | Backspace or Delete / Enter in the editor. |
| `rune` | A keyword was just finished (`SELECT`, `FROM`...): the word glows. |
| `locked` | A keyword of a rune Ada has not learned yet was typed. |
| `flatline` | The intro: Ada's heart stops (two beats, then the flat line). |
| `book` | The intro: the Grimoire appears. |
| `deflect` | A spell bounces off Sir Wherewell's Ward of Relevance. |
| `shatter` | A super-effective spell breaks the Ward of Relevance. |
| `ward_up` | The Knight raises his Ward of Relevance again. |
| `confirm` | ENTER on the title screen. |
| `next` | ENTER moves the dialogue on to the next line. |
| `victory` / `defeat` | The result screen. |

## Music

Music entries can list several files (`"files": [...]`): each battle picks one at random (with
the game's visual random generator, so the fight itself is unchanged) and never the one that
just played.

| Entry | When it plays |
|---|---|
| `dummy` | The tutorial (the calm Lantern over Codd). |
| `slime` / `knight` | The fight with that guardian: three themes each. |
| `battle` | Any fight without its own entry: all five themes. |
| `danger` | Replaces the battle theme while Ada's HP bar is below a quarter (back above 35%: the battle theme resumes where it was). |
| `classic_slime` / `classic_knight` | The two original chiptunes, kept but not used. |

| File | Piece |
|---|---|
| `theme_glade_jig.wav` | Glade Jig: D Dorian 6/8, recorder and lute, playful. |
| `theme_filter_keep.wav` | The Filter Keep: D Aeolian march, shawm in fifths, proud. |
| `theme_estampie.wav` | Estampie of Sparks: G Mixolydian 3/4 with hemiolas, fiddle and harp, heroic. |
| `theme_lantern.wav` | Lantern over Codd: E Aeolian, recorder over a harp ostinato, calm. |
| `theme_saltarello.wav` | Saltarello of the Spire: A Dorian 6/8, recorder and shawm in call and response, fast. |
| `danger_last_candle.wav` | Last Candle: E Phrygian, heartbeat, a bell circling E and F. |

They are made by `python -m tools.make_music` (score sheets in `docs/MUSIC.md`). A file of your
own works the same way: put it here and list it in `sounds.json`. Loops are seamless if the
file's last sample flows into its first.

## The placeholder kit

The sound effects (and the two classic themes) are chiptunes generated by
`tools/make_sounds.py` (square, triangle and noise waves, standard library only). To
regenerate them:

```bash
python -m tools.make_sounds
```

This overwrites the files with these names, so give your own sounds different names.
