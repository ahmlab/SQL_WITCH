# assets/audio/

Every sound the game plays, and `sounds.json`, which says which file plays for each event.

## Use your own sound

1. Put the file in this folder (`.wav` or `.ogg`; `.mp3` works for music).
2. In `sounds.json`, change the `file` of the event to your file name.
3. Adjust `volume` (0.0 to 1.0) if needed. `master_volume` scales everything.

No code changes are needed. If a file is missing, the game prints one warning and keeps
going without that sound.

## Events

| Event | When it plays |
|---|---|
| `hit` / `crit` | A spell lands (crit: a critical hit, with screen shake). |
| `hp_down` / `hp_up` | An HP bar drains (damage) or fills (heal, Healing Herb). |
| `mp_down` / `mp_up` | An MP bar drains (casting) or fills (end of round, Ether). |
| `cast` | A query that casts something is sent (Ada's or the Slime's). Also wards. |
| `scry` | A free look: a query that casts nothing. |
| `fizzle` | Spells fizzle: rows lost in the margin, duplicates, no MP left. |
| `miscast` | A rejected query: the book puffs smoke. |
| `invitation` | The Slime's `LIMIT` glows and Ada learns the rune. |
| `faint` | A combatant falls. |
| `confirm` | ENTER on the title screen. |
| `victory` / `defeat` | The result screen. |

Music: `battle` loops for the whole fight (fades in and out).

## The placeholder kit

The current files are chiptunes generated by `tools/make_sounds.py` (square, triangle and
noise waves, standard library only). To regenerate them:

```bash
python -m tools.make_sounds
```

This overwrites the files with these names, so give your own sounds different names.
